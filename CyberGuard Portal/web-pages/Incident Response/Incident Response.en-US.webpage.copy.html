Severity levels

Response steps

Every incident goes through these steps, based on NIST SP 800-61 Rev. 2.

  1. PrepareSensors in place, normal activity known, backups kept offline.
  2. Detect and triageConfirm the alert, set the severity and work out the scope.
  3. ContainIsolate hosts, revoke sessions, block what is bad.
  4. Remove and recoverClear persistence, rebuild from known-good, restore service.
  5. LearnReview the root cause within five working days and update detections.
